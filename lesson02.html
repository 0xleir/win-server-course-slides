概念 1

角色 vs 功能

角色 Role：服务器的"职业"

  • 对网络中的其他电脑提供服务
  • 例：AD DS、IIS（Web）、DHCP、DNS
  • 通常带有自己的服务和管理控制台

功能 Feature：服务器的"工具"

  • 辅助本机或支撑某个角色
  • 例：.NET、Telnet 客户端、SNMP
  • 单独装上，一般不对外提供服务
判断方法：别的电脑会不会来"找它要服务"？会 → 角色；不会 → 功能。
这是任务 1.3 要求记录的内容。提问：Telnet 客户端是角色还是功能？为什么？——它只让本机主动连别人，不对外服务，所以是功能。注意：在 PowerShell 里两者统一叫 WindowsFeature，用同一组命令管理。
概念 2

DHCP：自动发放 IP 地址

一台新电脑接入网络、请求地址的四步（DORA）：

① Discover客户端广播
"谁能给我地址？"
→
② OfferDC1 提供
10.10.10.100
→
③ Request客户端
"我要这个"
→
④ Ack确认租约
附带 DNS 等选项
术语含义
作用域 Scope一段可分配的地址池，本课是 10.10.10.100–200
租约 Lease地址不是永久给出，到期要续租
作用域选项随地址一起下发的参数，如 DNS 服务器
强调地址池 100–200 避开了 10.10.10.10、.20、.50 等静态地址，防止冲突。作用域建好后必须"激活"才会发地址，这是学生最常漏的一步。DNS 选项填 10.10.10.10，为第 17 课客户端加域埋下伏笔。
概念 3

DNS：把名字翻译成地址

DNS 服务器 DC1
正向查找区域 lab.local
📄 A 记录 dc1 → 10.10.10.10
名词含义
区域 ZoneDNS 服务器负责管理的一段名字空间
正向查找名字 → IP（本课只做正向）
A 记录一个主机名对应一个 IPv4 地址
区域文件记录保存在 lab.local.dns
查询效果：访问 dc1.lab.local → 区域 lab.local → A 记录 → 10.10.10.10
今天建的 lab.local 只是一个普通 DNS 区域，还不是"域"，第 17 课才会创建真正的 AD 域。提问：为什么人们记域名而不记 IP？反向查找（IP → 名字）后续 DNS 专题再讲。
概念 · 教材补充

系统服务与 Windows 日志

Windows 系统服务

  • 可在自身会话中长时间运行的程序
  • 随开机自动启动，可暂停/重启
  • 不显示任何用户界面（后台运行）
  • 角色装好后就是靠服务对外工作

Windows 日志类型

  • 应用程序日志 · 安全日志 · 系统日志
  • Scheduler 服务日志
  • FTP 日志 · WWW 日志 · DNS 服务器日志
  • 排障与安全审计都从日志入手
联系本课：DHCP、DNS 装完都会生成对应的后台服务，services.msc 里可查，运行状态和事件会写进系统/服务日志。
这页是对接教材"必备知识"的补充：教材把"系统服务""服务端口""日志"作为走进 Windows 服务器的基础概念。服务是没有界面的后台程序，角色（DHCP/DNS）本质上就是一组服务——这正好接上本课装的两个角色。日志按用途分成应用程序、安全、系统等多类，安全日志在后面的用户审计、密码攻击检测课会反复用到。可现场打开 services.msc 让学生找到 DHCP Server 和 DNS 两个服务。

任务 3 · 20′ · DC1

PowerShell 安装 DNS 角色

以管理员身份运行 PowerShell

# 查看已安装的角色和功能
Get-WindowsFeature | Where-Object {$_.Installed}

# 安装 DNS 服务器（含管理工具）
Install-WindowsFeature DNS -IncludeManagementTools

# 验证：Install State 应为 Installed
Get-WindowsFeature DNS
对比任务 2：GUI 点了 6–7 步，这里一行命令完成，还能写进脚本批量执行。
第一条命令的输出里应能看到刚才装的 DHCP 和 Telnet-Client，说明 GUI 和 PowerShell 管理的是同一份清单。-IncludeManagementTools 不加就没有 DNS 管理器控制台。可以让学生试 Get-WindowsFeature *dns* 体验通配符搜索。
任务 3 · 20′ · DC1

创建区域、添加记录、查服务


Add-DnsServerPrimaryZone -Name "lab.local" `
    -ZoneFile "lab.local.dns"
Add-DnsServerResourceRecordA -ZoneName "lab.local" `
    -Name "dc1" -IPv4Address "10.10.10.10"
Resolve-DnsName dc1.lab.local
Get-Service DHCPServer, DNS |
    Format-Table Name, Status, StartType
Resolve-DnsName 应返回 10.10.10.10
两个服务 Status = Running，StartType = Automatic
为了适应屏幕，这里用反引号续行，学生也可以写成一行，命令与手册完全一致。如果 Resolve-DnsName 失败，检查 DC1 网卡的 DNS 是否指向 10.10.10.10 或 127.0.0.1。管道符 | 结尾可以直接换行，不需要反引号。

排障

常见故障速查

现象原因处理
'telnet' 不是内部或外部命令功能未装完或窗口未刷新确认安装成功后重开命令行
DHCP 作用域有红色箭头作用域未激活右键作用域 → 激活
Add-DnsServer... 无法识别DNS 角色/管理工具未装重跑 Install-WindowsFeature DNS -IncludeManagementTools
Resolve-DnsName 找不到 dc1网卡 DNS 未指向本机DNS 设为 10.10.10.10，ipconfig /flushdns
命令提示"拒绝访问"PowerShell 非管理员右键 → 以管理员身份运行

本课小结

为什么

服务器的价值来自角色：角色对外服务，功能是辅助工具

怎么做

GUI：添加角色和功能向导；命令：Install-WindowsFeature

关键点

DHCP 作用域要激活；装角色带 -IncludeManagementTools
