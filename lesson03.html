概念

账户分类与强密码原则

内置账户

系统安装时自带，如 Administrator、Guest；不能随意删除

本地账户

建在本机 SAM 库里，只对这一台机器有效（本课重点）

域用户账户

建在域控制器上，可登录域内任意成员机（第 17 课）

Windows 密码管理原则

  • 身份验证最常用的方式就是密码，弱口令最易被攻破
  • 强密码：至少 8 位，由字母 + 数字 + 符号组合而成
  • 定期更换密码，降低被暴力破解 / 手工猜测成功的概率
教材把 Windows 账户分成三类：内置账户是系统装好就有的（Administrator、Guest），本地账户建在本机的 SAM 数据库里只能登录这一台机器，域用户账户建在域控制器上、可以登录域里任意一台成员机——今天建的全是本地账户，域要到第 17 课才搭。密码方面：在 Windows 上做身份验证最常用的就是密码，安全环境要求所有用户使用强密码——至少 8 个字符，并且包含字母、数字和符号的组合，这样能防止别人用手工或自动化工具猜出弱密码；再加上定期更换，就能进一步降低密码被攻破的可能。这也呼应任务里"密码永不过期"只是实验方便，生产环境该受密码策略约束，下节课就讲密码策略。

概念 1

本地账户存在哪里？

① 输入用户名密码username / password
→
② 查本机 SAM 数据库核对密码哈希
→
③ 取出 SIDS-1-5-21-…-1001
→
④ 生成访问令牌用户 SID + 所属组 SID
SAM：每台 Windows 自带的本地账户库，只对本机有效
SID：系统认的是 SID 而不是名字；删了重建同名用户，SID 已不同
可以现场演示 whoami /user 查看自己的 SID，whoami /groups 查看令牌里的组。强调"删除再重建同名用户，原来的权限全部失效"，因为权限绑定的是 SID。这页也为第 17 课的"工作组 vs 域"埋下伏笔。
概念 2

内置账户与内置组

名称类型说明
Administrator内置用户最高权限，不能删除；日常不应共用
Guest内置用户匿名来宾，默认禁用，必须保持禁用
Administrators内置组成员拥有本机完全控制权
Users内置组新建用户自动加入，只有普通权限
Remote Desktop Users内置组允许通过远程桌面登录
最小权限原则：账号只给完成工作所需的最低权限，别把人随手加进 Administrators。
提问：为什么 Guest 默认禁用还要专门检查？因为它无需密码，一旦被误启用，任何人都能访问共享资源，是攻防课上 Kali 常用的突破口。新建用户默认只在 Users 组，所以 alice 现在登录也做不了管理操作。
概念 3

为什么要用组？

直接给个人授权

  • 每个文件夹都要逐个添加用户
  • 新人入职 = 把所有权限再配一遍
  • 有人调岗时很容易漏删权限

用户 → 组 → 权限

  • 权限只授予组，组里放人
  • 新人入职：加入组即可
  • 调岗：换个组，权限自动跟随
本课的组规划（一个用户可同时属于多个组）
👥 IT-Admins：alice👥 IT-Users：bob, charlie👥 Finance：charlie👥 Developers：dave, frank
注意 charlie 同时属于 IT-Users 和 Finance，登录时令牌里会同时带上两个组的 SID，权限取并集。今天只建组、不分配权限，第 6 课 NTFS 权限会把这些组真正用起来。

任务 2 · 19′ · DC1

命令行创建用户

① 传统 net user 命令（cmd 和 PowerShell 都能用）

net user dave Lab@2026d /add `
    /fullname:"Dave Liu" /comment:"开发部"
net user eve Lab@2026e /add `
    /fullname:"Eve Chen" /comment:"市场部"
② PowerShell 原生命令：密码必须先转成 SecureString

$pw = ConvertTo-SecureString "Lab@2026f" -AsPlainText -Force
New-LocalUser -Name "frank" -Password $pw `
    -FullName "Frank Zhao" -Description "运维部" `
    -PasswordNeverExpires
对比两种方式：net user 简单但输出是文本；New-LocalUser 返回对象，能接管道、能写进脚本做判断。提问：为什么 -Password 不能直接写字符串？——防止密码以明文形式留在内存和历史记录里。反引号续行后面不能有空格。

任务 3 · 19′ · DC1

批量创建脚本


$users = Import-Csv C:\LabFiles\users.csv
foreach ($u in $users) {
  $pw = ConvertTo-SecureString $u.Password -AsPlainText -Force
  New-LocalUser -Name $u.Username -Password $pw `
    -FullName $u.FullName -Description $u.Department `
    -PasswordNeverExpires
  Write-Host "已创建: $($u.Username)" -ForegroundColor Green
}
验证：Get-LocalUser | Measure-Object
预期：Count 至少 11（Administrator + 6 个手动 + 5 个批量），内置的 Guest 等账户也会计入
逐行讲解：Import-Csv 把每一行变成一个对象，foreach 依次处理。建议学生先把脚本保存成 .ps1 再运行，方便修改。如果重复运行，会报"用户已存在"，这正好引出改进思路：先用 Get-LocalUser -ErrorAction SilentlyContinue 判断再创建。
排障

创建失败？先看报错

现象原因处理
拒绝访问PowerShell 未以管理员运行右键"以管理员身份运行"
密码不满足策略要求复杂度 / 长度不够严格使用原文密码，如 Lab@2026a
用户已存在重复执行了命令或脚本Get-LocalUser 确认后跳过
找不到文件 users.csv路径错或扩展名变成 .txt检查 users.csv
无法加载脚本文件执行策略限制确认第 1 课已设 RemoteSigned
让学生先读红字报错的第一行，再对照这张表。密码策略报错时，net user 会显示"密码不满足密码策略的要求"，New-LocalUser 会报 InvalidPasswordException。执行策略在第 1 课已设置为 RemoteSigned，如果回滚过快照可能需要重新设置。
