概念

IIS 是什么 · 版本与 Windows 的对应

IIS 的功能

  • Windows 自带的互联网信息服务（Internet Information Services）
  • 提供 Web（HTTP/HTTPS）、FTP 等网络发布服务
  • 通过"服务器管理器 → 添加角色"安装"Web 服务器(IIS)"
  • 用 IIS 管理器统一配置站点、绑定与权限
IIS 版本对应 Windows
IIS 7.0Windows Server 2008 / Vista / 7
IIS 8.0Windows Server 2012
IIS 10Windows Server 2016 / 2019 / 2022
本课环境：Windows Server 2022 自带 IIS 10（教材截图是 2019，界面基本一致）。
这页补充教材里的"必备知识"：IIS 全称 Internet Information Services，是 Windows 自带的互联网信息服务，主要用来对外发布网站和 FTP 服务，安装方式是在服务器管理器里添加"Web 服务器(IIS)"这个角色，装好后用 IIS 管理器来配置站点和参数。IIS 的版本和 Windows 版本是绑定的：Windows Server 2008 对应 IIS 7，2012 对应 IIS 8，2016 和 2019 都用 IIS 10。只要记住"换系统就换 IIS 版本、功能越新越强"即可。我们今天用的 Windows Server 2022 自带的同样是 IIS 10（教材用 2019，界面几乎一样）。

状态码含义本课何时会遇到

概念 2

IIS 的层级结构

IIS 服务器（W3SVC 服务）
站点 CompanySite · 绑定 *:80
📄 index.html📄 home.html
目录 /docs
📄 file1.txt📄 file2.txt
站点 Default Web Site（今天停用）
名词含义
W3SVCIIS 的 Web 发布服务，停了所有站点都不可用
站点一个独立网站，有名称、物理路径、绑定
物理路径站点根目录在磁盘上的位置
绑定协议 + IP + 端口 + 主机名，决定"谁来接请求"
强调：两个站点不能使用完全相同的绑定，所以今天要先停用 Default Web Site，再让 CompanySite 占用 80 端口。应用程序池、虚拟目录下节课再讲，这里只提一句它们存在。

任务 1 · 16′ · DC1

安装 IIS（含常用子功能）

在 DC1 上，以管理员身份运行 PowerShell

Install-WindowsFeature Web-Server -IncludeManagementTools

Install-WindowsFeature Web-Asp-Net45, Web-CGI, `
  Web-ISAPI-Ext, Web-ISAPI-Filter, Web-Basic-Auth, `
  Web-Windows-Auth, Web-Filtering, Web-IP-Security, `
  Web-Stat-Compression, Web-Log-Libraries
Web-Server 是 IIS 本体；-IncludeManagementTools 带上 IIS 管理器 inetmgr。
反引号 ` 是续行符，后面不能有空格；子功能名用逗号分隔。
第二条命令装的是后续课程要用的组件：身份验证（第 11 课左右）、IP 限制、请求筛选、压缩、日志。今天的静态网站其实只需要第一条，但一次装齐避免后面反复安装。安装约 2–3 分钟，一般不需要重启，留意输出中的 Restart Needed 列。
任务 1 验证

IIS 装好了吗？


Get-WindowsFeature Web-* | Where-Object {$_.Installed}
Get-Service W3SVC | Format-Table Name, Status
检查看到这个说明成功
Get-WindowsFeature列出 Web-Server 及刚装的子功能，前面是 [X]
Get-Service W3SVCStatus = Running
DC1 浏览器打开 http://localhost出现 IIS 默认欢迎页（蓝色 IIS 图标）
W3SVC 是"万维网发布服务"，IIS 站点都靠它运行。看到欢迎页说明 Default Web Site 已经在 80 端口工作——这正是任务 2 要先把它停掉的原因。服务器版 IE 增强安全配置可能弹出提示，localhost 一般可直接访问。
任务 2 · 24′ · DC1

准备网站文件

先建目录：mkdir C:\WebSites\CompanySite，再生成首页

$html = @"
<!DOCTYPE html><html><head><title>Lab Company</title></head>
<body><h1>Welcome to Lab Company</h1>
<p>Server: DC1 | IP: 10.10.10.10</p>
<p>Current Time: <span id="time"></span></p>
<script>document.getElementById('time').textContent =
  new Date().toLocaleString();</script></body></html>
"@


$html | Out-File -FilePath `
  C:\WebSites\CompanySite\index.html -Encoding UTF8
@" 和 "@ 之间是 here-string，可以写多行文本；结尾的 "@ 必须顶格写在行首。这里先存进变量 $html 再写文件，效果与手册里直接管道写入相同。可以让学生用记事本打开 index.html 确认内容。
任务 2 · 24′ · DC1

在 IIS 管理器中添加网站

Win+R 输入 inetmgr›DC1›网站›Default Web Site›停止
右键"网站"›添加网站›填写下表›确定并启动
字段本课取值说明
网站名称CompanySite自查清单按此名称核对
物理路径C:\WebSites\CompanySite站点根目录
绑定http · IP = 全部未分配(*) · 端口 80监听本机所有 IP
主机名（留空）不按域名区分站点
先停 Default Web Site！它也占用 *:80，不停会提示绑定冲突，新站点无法启动。
让学生对照概念 2 的层级图理解：名称、物理路径、绑定就是一个站点的三要素。主机名留空意味着任何访问 80 端口的请求都交给它，下节课会用主机名区分 www 和 hr 两个站点。
任务 2 验证

从服务器和客户端访问

① DC1 本机

浏览器访问 http://10.10.10.10

或用命令查看状态码：


(Invoke-WebRequest http://10.10.10.10 `
  -UseBasicParsing).StatusCode

② CLIENT1（VM3）

浏览器访问 http://10.10.10.10

  • 标题 Welcome to Lab Company
  • 显示当前时间
本机能开、客户端打不开？多半是 DC1 防火墙未放行 80 端口，见排障页。
Invoke-WebRequest 返回 200 即成功，这是补充的命令行验证方法，人工核对清单时也可用它快速确认。时间是客户端浏览器里的 JavaScript 算出来的，可以提问：显示的是服务器时间还是客户端时间？答案是客户端。
任务 3 · 16′ · DC1

启用 /docs 的目录浏览


mkdir C:\WebSites\CompanySite\docs
$d = "C:\WebSites\CompanySite\docs"
"Document 1" | Out-File $d\file1.txt
"Document 2" | Out-File $d\file2.txt
IIS 管理器›CompanySite›docs›目录浏览›右侧"启用"
访问 http://10.10.10.10/docs/ → 看到 file1.txt、file2.txt 列表
注意选中 docs 再设置，不要在站点根上启用，否则整站目录都可被浏览。
$d 只是保存路径的变量，写出的文件与手册完全相同。docs 是站点下的普通子目录，IIS 管理器会自动显示它，不需要另建虚拟目录（虚拟目录下节课讲）。启用前先访问一次 /docs/，让学生看到 403 错误，再启用对比，正好呼应概念 3 的流程。
任务 3 · 16′ · DC1

配置默认文档


"This is home.html" |
  Out-File C:\WebSites\CompanySite\home.html -Encoding UTF8
IIS 管理器›CompanySite›默认文档›添加 home.html›上移到顶部
1. home.html存在 → 返回
→
2. Default.htm…不再检查
→
… index.html不再检查
再次访问 http://10.10.10.10 → 显示 This is home.html。
在 IIS 管理器中"添加"的条目默认就放在列表顶部，如不在顶部用右侧"上移"。浏览器有缓存，看到的还是旧页面时按 Ctrl+F5 强制刷新。提问：想恢复显示 index.html，有哪两种办法？（调整顺序或删除 home.html）
排障

网页打不开？按这个顺序查

现象原因处理
CompanySite 无法启动Default Web Site 仍占用 *:80先停止 Default Web Site 再启动
仍显示 IIS 欢迎页访问到的是默认站点或浏览器缓存确认站点状态，Ctrl+F5 刷新
CLIENT1 连接超时防火墙未放行 80 或网络不通启用"万维网服务(HTTP 流量入站)"规则，ping 测试
/docs/ 返回 403目录浏览未启用在 docs 节点启用目录浏览
页面中文乱码文件编码与页面声明不一致保持 -Encoding UTF8
防火墙规则在"高级安全 Windows Defender 防火墙 → 入站规则"中，安装 IIS 时通常会自动创建并启用，但如果之前改过防火墙配置可能被关掉。可以用 Test-NetConnection 10.10.10.10 -Port 80 在 CLIENT1 上测试端口。先让学生自己猜原因再揭示答案。
