概念 1

Windows Server 2022 选哪个版本？

版本定位虚拟化授权
Essentials小企业，≤ 25 用户无
Standard ← 本课物理机或少量虚拟化2 个虚拟机
Datacenter大规模虚拟化、云数据中心不限数量

桌面体验 Desktop Experience

有图形界面和服务器管理器，适合学习和中小企业

服务器核心 Server Core

只有命令行，体积小、补丁少、攻击面小，生产环境推荐

版本区别主要是授权和高级功能，核心角色（AD、DNS、IIS）各版本都有。我们用 180 天评估版，功能等同正式版。提问：为什么 Server Core 更安全？（组件少 = 漏洞少 = 补丁少）。安装后不能在 Core 和桌面体验之间来回切换，装错只能重装。
概念 2

服务器为什么要"固定身份"？

默认状态（像个人电脑）

  • 计算机名随机：WIN-XXXXXXX
  • IP 由 DHCP 分配，重启可能变化
  • 别人记不住、也找不到它

服务器状态（今天的目标）

  • 有意义的名字：DC1
  • 静态 IP：10.10.10.10/24
  • DNS 指向自己：127.0.0.1
一句话：服务器是"被别人访问"的机器，名字和地址必须稳定，客户端才能一直找到它。
DNS 设为 127.0.0.1 是为第 17 课做准备：DC-学号 以后自己就是 DNS 服务器。网关留空是因为 VMnet-Lab 是隔离的实验网，上网走 NIC2 的 NAT。提问：如果 DHCP 服务器本身的 IP 也是 DHCP 分配的，会发生什么？
概念 3

PowerShell：管道里传的是"对象"

Get-Service取出所有服务对象
→
Where-Object按 Status 属性筛选
→
Measure-Object计数
写法含义
动词-名词命令命名规则：Get / Set / New / Remove…
|管道：把左边的输出交给右边
$_管道中"当前这一个对象"
-eq等于（不是 = 或 ==）
与 CMD 对比：CMD 的 findstr 处理的是文本行，PowerShell 处理的是带属性的对象，所以可以直接按 Status、CPU 排序和筛选。学生最常见错误是把 -eq 写成 ==，或者 $_ 后面忘了点号。

以 Administrator 登录，观察自动弹出的服务器管理器仪表板，然后打开 PowerShell：


systeminfo | findstr /B /C:"OS Name" /C:"OS Version"
Get-WindowsFeature | Where-Object {$_.Installed -eq $true}

📝 记录：版本号、已安装功能、计算机名、IP 地址 —— 任务 2 结束后对比变化。

任务 2 · 24′ · WinSrv-Main → DC1

改计算机名、配静态 IP

① 修改计算机名（完成后重启）
设置›系统›关于›重命名这台电脑›输入 DC1›重启
② 配置静态 IP：运行 ncpa.cpl
右键 NIC1 (VMnet-Lab)›属性›Internet 协议版本 4 (TCP/IPv4)
项目取值
IP 地址10.10.10.x
子网掩码255.255.255.0
默认网关（空）
首选 DNS127.0.0.1
只改 NIC1！NIC2 (NAT) 保持 DHCP，否则无法联网激活。

验证：ping 10.10.10.x
先确认哪块是 NIC1：在 ncpa.cpl 里网卡名通常是 Ethernet0/Ethernet1，可用 ipconfig /all 看哪块拿到的是 NAT 网段地址来区分。改名必须重启才生效，可以先改 IP 再统一重启。常见错误：把 IP 配到了 NAT 网卡上。
任务 2 · 24′ · DC1

关闭 IE 增强安全、放行 ping

③ 关闭 IE 增强安全配置（IE ESC）
服务器管理器›本地服务器›IE 增强的安全配置›管理员：关闭
④ 新建防火墙规则，允许 ICMP 回显请求（ping）

New-NetFirewallRule -DisplayName "Allow ICMPv4" `
    -Protocol ICMPv4 -IcmpType 8 -Action Allow
IcmpType 8 = Echo Request，即别人 ping 你时发来的包
反引号 ` 是续行符，后面不能有空格
IE ESC 会拦截几乎所有网页，实验环境关掉方便下载工具；生产服务器上不应该用浏览器上网，所以默认开启是合理的。Windows Server 默认防火墙阻止入站 ping，第 6 课客户端加入后需要 ping 通 DC1，所以现在先放行。提问：放行 ping 有什么安全代价？

配置生效了吗？

    -AddressFamily IPv4

hostnameDC1

Get-DnsClientServerAddressNIC1 的 ServerAddresses = 127.0.0.1

任务 3 · 24′ · DC1

PowerShell 常用命令

3.1 查询系统状态

Get-Service | Where-Object {$_.Status -eq "Running"} |
    Measure-Object
Get-Process | Sort-Object CPU -Descending |
    Select-Object -First 10
Get-EventLog -LogName System -Newest 5
Get-NetIPAddress -InterfaceAlias "Ethernet*"
3.2 帮助系统

Update-Help -Force -ErrorAction SilentlyContinue
Get-Help Get-Service -Examples
Get-Command *firewall*
不会就问 Get-Help：先 Get-Command 找命令，再 Get-Help -Examples 看用法。
管道符 | 放在行尾时可以直接换行，不需要反引号；学生也可以写成一行。Update-Help 需要联网（走 NAT 网卡），离线时会失败，加了 SilentlyContinue 不会报红字，但 -Examples 可能只显示简略帮助。让学生回答：当前有多少个服务在运行？CPU 占用最高的进程是什么？
任务 3 · 24′ · DC1

脚本执行策略与实验目录

3.3 允许运行本地脚本（PowerShell 自动化基础）

Get-ExecutionPolicy
Set-ExecutionPolicy RemoteSigned -Force
策略本地脚本网上下载的脚本
Restricted✗ 禁止✗ 禁止
RemoteSigned ← 本课✓ 允许需要数字签名
Unrestricted✓ 允许✓ 允许（有提示）
3.4 创建实验工作目录

New-Item -Path C:\LabFiles -ItemType Directory -Force
New-Item -Path C:\LabFiles\Lesson01 -ItemType Directory
Windows Server 2022 默认策略是 RemoteSigned，Windows 10 客户端默认是 Restricted，所以先 Get 再 Set，让学生观察。执行策略不是安全边界，只是防止误触运行未知来源的代码。C:\LabFiles 模板里可能已存在，第一条加了 -Force 不会报错；第二条重复执行会报"已存在"。

常见故障速查

现象原因处理
